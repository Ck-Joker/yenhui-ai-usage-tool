Subscription Pin 1.1.0 · macOS · Apple silicon

安裝浮窗，用自己的帳號查看剩餘用量

這個小工具讓你隨時查看 Codex、Claude Code 與平台提供的 Fable 額度。安裝包不含開發者的帳號或登入資料；每位使用者都需要在自己的 Mac 完成登入。

安裝前確認
需要 Apple silicon Mac（M 系列晶片），系統最低 macOS 13。此版未提供 Intel 版本；目前實機驗證為 macOS 26。已內附執行元件，不需要另外安裝 Python 或 Xcode。兩個平台各自需要能提供訂閱額度的帳號，API 金鑰不能代替訂閱登入。

1　把 App 放進「應用程式」

  1. 開啟收到的 Subscription-Pin-1.1.0-AppleSilicon.dmg。
  2. 將 Subscription Pin.app 拖曳到視窗中的 Applications 資料夾。
  3. 從 Finder 的「應用程式」開啟 Subscription Pin，再退出 DMG。請勿一直從安裝映像內執行。

這份分享版尚未取得 Apple Developer ID 簽署與公證。若 macOS 阻擋開啟，請先確認檔案確實來自你信任的提供者，再依「系統設定 → 隱私權與安全性 → 強制打開」完成系統確認。若顯示惡意軟體、檔案損毀或公司管理限制，請停止並聯絡提供者，不要停用系統保護。詳見 Apple 官方開啟 App 說明。

2　登入自己的 Codex

在引導視窗按「Codex 安裝說明」，依 OpenAI 官方說明安裝 App，並登入自己的 ChatGPT 訂閱帳號。官方下載頁目前使用 ChatGPT 桌面 App 名稱，既有 Codex App 也可使用。已安裝者可按「開啟 Codex」。只使用 Codex CLI 的使用者，請先在終端機執行 codex login 完成登入。

3　登入自己的 Claude Code

  1. 按引導視窗的「Claude Code 安裝說明」，依 Claude Code 官方快速入門安裝 CLI。
  2. 按「複製登入指令」，再按「開啟終端機」，貼上 claude auth login 並按 Enter。
  3. 依開啟的瀏覽器提示，登入自己的 Claude 訂閱帳號並完成官方要求的驗證。只有登入 Claude 桌面聊天 App，可能不足以提供 CLI 的登入資訊。

若看到 command not found，請先完成官方安裝，關閉再開啟終端機。原生安裝的 CLI 也可使用 ~/.local/bin/claude auth login。

4　同意讀取並驗證

  1. 回到 Subscription Pin，勾選「我同意讀取這台 Mac 上自己的訂閱用量」。
  2. 按「驗證連線」。如果 macOS 詢問鑰匙圈存取，請核對為本工具的 usage-helper。本工具只讀取既有登入，不會要求你把密碼或 token 貼進小工具。
  3. 確認每個已登入的平台顯示「已驗證」，再按「開始使用浮窗」。至少一個平台成功即可使用，另一個可稍後從選單列「登入與使用引導」補設。

浮窗會顯示剩餘百分比與單行重置倒數。未提供的額度不會補成 100%；Fable 只有平台回傳時才會出現，不能與一般週額度相加。

日常使用與常見狀態

  • 固定位置：拖曳標題或背景到適合的位置，按圖釘保持最上層，再按鎖頭鎖定。精簡版寬 180px。
  • 更新：Codex 至少間隔 1 分鐘，Claude 至少間隔 5 分鐘。按更新、重新開啟或喚醒，都沿用冷卻期限；倒數每 15 秒在本機更新。
  • 查詢冷卻：等畫面倒數結束。Claude 遇到限流時依序等待至少 10、20、40、60 分鐘，或遵守平台要求的更長時間，不需反覆重新登入。
  • 請更新登入：Claude 平常會在登入到期時自動請 Claude Code 換發。仍出現提示時，將滑鼠停在圖示上查看原因，再到終端機執行 claude auth login；Codex 請開啟 Codex 檢查登入。完成後等下一次排程更新。
  • 收起／結束：從 macOS 選單列的 C／A／F 用量選單操作；也可在浮窗按右鍵。系統安全提示或部分全螢幕 App 仍可能蓋住浮窗。

資料保存與移除

Codex 透過官方 App Server 讀取本機登入帳號；Claude 使用這台 Mac 鑰匙圈中的 Claude Code 憑證，向 Anthropic 用量端點查詢。憑證僅在程序記憶體中使用，不寫入用量快取，也不送往言回伺服器。Claude 登入到期時，本工具會執行本機的 claude 指令送出一次極小請求，由 Claude Code 自行換發登入；每 30 分鐘最多一次，會少量計入 Claude 用量，本工具不使用也不改寫 refresh token。除此之外，本工具不購買點數，不消耗重置券，也不執行模型推論。

本機只保存查詢結果、冷卻期限與顯示偏好。用量資料位於使用者的 ~/Library/Application Support/Subscription Pin，偏好位於 macOS 的 tw.ckc.subscription-pin 設定網域。平常請保留冷卻資料，避免失去限流保護。平台登入仍由各自的官方工具管理。

移除時先結束 Subscription Pin，再將 App 移到垃圾桶即可；不會登出 Codex 或 Claude Code。需要清除本工具的本機資料時，可另將上述用量資料夾移到垃圾桶。Claude 用量端點可能隨官方版本改變，若持續無法查詢，請向提供者取得更新版。
